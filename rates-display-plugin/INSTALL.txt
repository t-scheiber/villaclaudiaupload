INSTALLATION AND RECOVERY

Back up the existing plugin and Rates page before replacing the plugin. Keep
backups outside the public web directory.

Install villa-claudia-rates-display.zip through WordPress Plugins > Add New >
Upload Plugin. If WordPress finds the existing plugin, review the versions
before replacing it. Only one Villa Claudia rates display plugin should be
active.

Use this shortcode on the Rates page:
  [villa_claudia_rates]

The default shows the current year and the next year when MotoPress supplies
matching season periods. Each table is labelled with its year. Recurring
seasons use MotoPress's generated periods, including recurrence end dates
and its booking horizon. The display does not create or change rates.

To show one specific year:
  [villa_claudia_rates year="2027"]

An explicit year with no matching periods does not display another year's
prices. The optional show_note="off" setting hides the explanatory note.

If an update breaks the page, deactivate this plugin and restore the saved
version. If WordPress administration is unavailable, rename this plugin's
directory through Hostinger File Manager to deactivate it, then restore the
backup. Do not delete unrelated plugin directories.
